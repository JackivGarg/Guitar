# Learn around the guitar

The original six camera chapters and black Yamaha FS80C remain the visual foundation. The new controls add physical learning to those same views.

## Explore

- **Strings:** hear each open string and identify it on your own guitar.
- **One clear note:** select a string and fret 0–4. The 3D marker follows the selected string; open notes show OPEN without a finger-pressure marker. Hear the named pitch, then compare your own note. The chosen fretboard view stays held until Resume scroll view.
- **Chord shapes:** select C, Am, Em, E, D, A or G. Numbered positions on the neck and the accompanying diagram use the same verified finger data. C↔Am keeps index on B1 and middle on D2 while ring travels A3↔G2. Other shapes remain individual chord studies; their markers do not invent a new shifting method.
- **Pulse:** choose 40–80 BPM, hear four beats or keep looping, then practise actual downstrokes. The sound stops when the page hides, tools open or the selected chapter changes.
- **Practice here:** explicitly start the timer, pause, count self-reported clean repetitions and optionally rate comfort. Save before leaving Explore. Only observed foreground time is counted. A save writes the complete pending batch before reporting success; a failed write retains the paused draft for retry. Time and self-reports never complete a foundation automatically.

## Quick changes

Open Changes from the main navigation or the guitar’s chord chapter. All eleven original groups are immediately selectable. Each exposes its own subtypes, including the separate Fmaj7 and small-F variations. The full connected sequence and return route remain visible.

Choose a direction, inspect the complete image, or watch a short clip. One direction takes three seconds at normal speed; a round trip takes six. Speed and movement-step controls let you inspect release, movement groups and landing. Group 2 begins Am→C, as its exercise requires. The canonical instructions for both directions remain available beside the image. The exact source data in `src/lesson7.ts` is unchanged.
